# Private Region Tutorial

Private Region connects your local GPU/CPU machines to the cloud, allowing you to use those machines directly from anywhere. It also provides machine resource monitoring and utilization statistics, helping you track the compute, storage, and network resources in your Region in real time and manage your infrastructure more efficiently.

Core features:

- **Dashboard**: Visualize the status of compute and storage nodes, usage hours for the current month, resource utilization, and GPU usage.
- **Region management**: Filter Regions and view their IDs, names, owners, notes, and creation times.
- **Compute node management**: View server specifications, CPU/GPU information, MIG configuration, and utilization status.
- **Storage node management**: Monitor storage capacity, utilization, disks, RAID, and other information.
- **Network visualization**: Use a network topology to view node connections, IP addresses, public network egress, switches, and real-time upload and download bandwidth.

## Feature Overview

### Machine Rental

After your Private Region is deployed, you can rent your machines on the Glows.ai platform. You define the machine prices and configurations, and can also use platform features such as prebuilt Images and Autodeploy.

![ ](../docs-images/p20/01.png)

### Dashboard Monitoring Data

In the Glows.ai Platform, click `Private Region` to view monitoring data for your machines, including usage hours and utilization statistics. You can also click `View More` to open `Compute Node` and view more details about your machines.

![ ](../docs-images/p20/02.png)

Scroll down to view machine usage trends for the current month, the past three months, the past six months, and the past 12 months.

![ ](../docs-images/p20/03.png)

View the available resource data for your machines.

![ ](../docs-images/p20/04.png)

### Compute Node Monitoring Data

The `Compute Node` page provides more detailed machine usage data, including total usage hours, utilization for the current month, and resource status. Click an individual resource to view its configuration details.

![ ](../docs-images/p20/05.png)

Click `Node Monitor` to view utilization trends for the machine's GPU, CPU, disk, RAM, and bandwidth.

![ ](../docs-images/p20/06.png)

Private Region provides unified resource management and visual monitoring, making compute, storage, and network resources more intuitive, efficient, and flexible to manage. It helps individuals and businesses simplify administration, improve resource utilization, and build a more flexible and scalable compute infrastructure.
