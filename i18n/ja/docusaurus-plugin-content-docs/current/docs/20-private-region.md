# プライベートリージョン チュートリアル

Private Region は、ローカルの GPU/CPU マシンをクラウドに接続し、どこからでもローカルの GPU/CPU マシンを直接利用できるようにします。マシンリソースの監視や使用率の統計情報も提供するため、Region 内のコンピューティング、ストレージ、ネットワークの状態をリアルタイムで把握し、インフラ管理の効率を高めることができます。

主な機能：

- **Dashboard**：コンピューティングノードとストレージノードの概要、当月の使用時間、リソース使用率、GPU 使用状況を可視化します。
- **Region 管理**：Region を絞り込み、ID、名前、所有者、メモ、作成日時を確認できます。
- **コンピューティングノード管理**：サーバーの仕様、CPU/GPU 情報、MIG 構成、使用状況を確認できます。
- **ストレージノード管理**：ストレージ容量、使用率、ディスク、RAID などの情報を監視できます。
- **ネットワークの可視化**：ネットワークトポロジーでノード接続、IP アドレス、パブリックネットワークの出口、スイッチ、リアルタイムの上り下り帯域幅を確認できます。

## 機能の開通

現在、Private Region はビジネス窓口を通じてのみ利用を開始できます。ご利用を希望される場合は、[こちらをクリック](#お問い合わせ)してお問い合わせください。担当のビジネスチームがご要望を伺います。

## 機能紹介

### マシンのレンタル

Private Region のデプロイが完了すると、Glows.ai プラットフォーム上でマシンをレンタルできます。マシンの価格と構成は自由に設定でき、プラットフォームのプリセット Image や Autodeploy などの各種機能も利用できます。

![ ](../../../../../docs/docs-images/p20/01.png)

### Dashboard のモニタリングデータ

Glows.ai Platform で `Private Region` をクリックすると、マシンの使用時間や使用率などのモニタリングデータを確認できます。`View More` をクリックすると `Compute Node` が開き、マシンの詳細データを確認できます。

![ ](../../../../../docs/docs-images/p20/02.png)

画面を下にスクロールすると、当月、過去 3 か月、過去 6 か月、過去 12 か月のマシン使用時間の推移を確認できます。

![ ](../../../../../docs/docs-images/p20/03.png)

マシンで利用可能なリソースデータを確認できます。

![ ](../../../../../docs/docs-images/p20/04.png)

### Compute Node のモニタリングデータ

`Compute Node` 画面では、総使用時間、当月の使用率、リソースの状態など、マシン使用状況の詳細を確認できます。各リソースをクリックすると、マシンの構成情報を確認できます。

![ ](../../../../../docs/docs-images/p20/05.png)

`Node Monitor` をクリックすると、マシンの GPU、CPU、ディスク、RAM、帯域幅の使用率推移を確認できます。

![ ](../../../../../docs/docs-images/p20/06.png)

Private Region は、リソースを一元管理し、状態を可視化して監視できる機能を提供します。コンピューティング、ストレージ、ネットワークの管理をより直感的かつ効率的、柔軟に行えるため、個人や企業の管理プロセスを簡素化し、リソース利用率を高め、より柔軟で拡張性の高いコンピューティング基盤を構築できます。
