# Datadrive

Datadrive は Glows.ai が提供するクラウドストレージです。インスタンス作成時に仮想マシンやコンテナへマウントでき、異なるインスタンス間でデータへアクセス・共有することができます。

---

## **Datadrive メイン画面**

サイドバーの **Data Drive** をクリックすると画面に移動します。この画面には保存されているデータが直接表示され、さまざまな操作機能が用意されています。直感的なインターフェースでデータファイルを管理できます。
  ![](../../../../../docs/docs-images/p06/01.png)


この画面には各リージョンのタブが表示されます。異なるリージョンの Datadrive データは互いに独立しています。例：
  1. **JP-01**
  2. **TW-03**
  3. **TW-04**
  ![](../../../../../docs/docs-images/p06/02.png)

---

## **メイン画面のボタン機能**

![](../../../../../docs/docs-images/p06/03.png)


### **1. Refresh**

- **機能**：一覧を更新し、ファイルとフォルダの最新状態を表示します。

### **2. New Folder**

- **機能**：新しいフォルダを作成します。
- **操作手順**：
  1. **New Folder** ボタンをクリックします。
  2. 表示されるダイアログにフォルダ名を入力します。
  3. 確定すると、新しいフォルダが一覧に表示されます。

### **3. Upload**

- **機能**：現在のリージョン（例：`JP-01`、`TW-04` など）にファイルをアップロードします。
  >注意：Datadrive の Web 版はフォルダのアップロードに対応していません。フォルダをアップロードする場合は、Datadrive デスクトップ版をご利用ください。
- **操作手順**：
  1. **Upload** ボタンをクリックします。
  ![](../../../../../docs/docs-images/p06/04.png)

  2. アップロードするファイルを選択します。
  ![](../../../../../docs/docs-images/p06/05.png)

  3. アップロードが完了すると、ファイルが一覧に表示されます。


---

## **ファイルとフォルダの一覧**

Datadrive のメイン画面には、すべてのファイルとフォルダの一覧が表示され、以下の項目を含みます：

- **Name**：ファイルまたはフォルダの名前。
- **Size**：ファイルまたはフォルダのサイズ。
- **Last Modified**：ファイルまたはフォルダの最終更新日時。
![](../../../../../docs/docs-images/p06/06.png)


### **ファイル操作ボタン（Actions）**

いずれかの行をクリック、またはマウスホバーすると、以下の操作オプションが表示されます：

- **Download**：指定したファイルをダウンロードします。
  > **注意**：この機能はファイルにのみ対応しており、フォルダは直接ダウンロードできません。
- **Move**：ファイルまたはフォルダを別の場所に移動します。
- **Rename**：名前を変更します。
- **Delete**：指定したファイルまたはフォルダを削除します。
![](../../../../../docs/docs-images/p06/07.png)

## **Datadrive のマウント／利用**

### インスタンス作成時に Datadrive をマウントする

 **操作手順**：
  1. `Create New` をクリックしてインスタンス作成を開始し、詳細設定内の **Mount Datadrive** 項目で `Mount` をクリックします。
    ![](../../../../../docs/docs-images/p06/08.png)

  2. **Mount Datadrive ポップアップの情報**：
    - **Region**：マウントする Datadrive のリージョンを選択します（例：`TW-03` など）。
      > 注意：インスタンスは同じリージョンの Datadrive のみマウントできます。
    - **Usage**：そのリージョンの Datadrive の現在の使用容量／総容量。
    - **Mount Path**：Datadrive がインスタンス内でマウントされるパス。デフォルトは `/datadrive` です。
    - **Permissions**：マウント後の読み書き権限。`Read only` または `Read & write` を選択できます。
    - `Mount` をクリックした後、インスタンスを作成するとマウントが完了します。
      ![](../../../../../docs/docs-images/p06/09.png)

  3. **インスタンスの作成**：

      マウントが成功すると Datadrive の情報が表示されます。内容を確認したら `Complete Checkout` をクリックすると、Datadrive がマウントされたインスタンスを作成できます。
      ![](../../../../../docs/docs-images/p06/10.png)

### インスタンス内で Datadrive を利用する

 **操作手順**：
  1. Datadrive をマウントしたインスタンスを作成後、インスタンス一覧でそのインスタンスの Datadrive タブをクリックすると、Datadrive の情報を確認できます。
  ![](../../../../../docs/docs-images/p06/11.png)


  2. インスタンスに SSH でログイン後、デフォルトパス `/datadrive` から Datadrive のデータにアクセスできます。
   ![](../../../../../docs/docs-images/p06/12.png)

## **注意事項**

1. **ファイル・フォルダ操作について**：
   - フォルダは直接ダウンロードできない点にご注意ください。
   - 削除・移動操作を行う場合は、必ず対象項目を選択してください。

2. **命名規則について**：
   - 名前を編集する際は、特殊文字や重複する名前の使用を避けてください。

3. **ファイルサイズの制限について**：
   - ファイルをアップロードする際は、システムで許可されているサイズ上限内であることを確認してください。

以上が **Datadrive** ページの機能に関する説明です。さらにサポートが必要な場合は、関連ガイドをご参照ください。
