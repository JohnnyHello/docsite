# Billing System

**Billing** ページでは、支出と残高を確認・管理できます。

## Billing メイン画面
### 上部ダッシュボード

- **Balance (Credit)**：現在の残高（例：11.860）。クリックするとクレジットの詳細確認とチャージができます。
- **Total Spending (Credit)**：総支出額（例：83.150）。
- **Total Duration (h)**：総利用時間（例：520.8 時間）。
- **Invoicing Limit (Credit)**：現在は上限なし。
![](../../../../../docs/docs-images/p11/01.png)

### My Spending

- 各取引の詳細情報（**Time, Name, Status, Payment**）を表示します。
- 取引タイプ（**Instances, Others**）でフィルタリングすることもできます。
![](../../../../../docs/docs-images/p11/02.png)

## **Credits のチャージ**

1. **My Spending** の右側にある `Recharge` ボタンをクリックします。
2. クリックするとチャージ画面に移動し、**My Balance** と **Buy Credit** のオプションが表示されます。
   > プリセット金額を選択することも、チャージ額を自分で指定することもできます。
3. **Payment Currency**（現在 USD と TWD に対応）を選択します。
4. **Payment Method**（現在 PayPal、NewebPay、Stripe に対応）を選択します。
5. 表示された金額が正しいことを確認し、**Recharge** をクリックしてチャージを完了します。

![](../../../../../docs/docs-images/p11/03.png)
![](../../../../../docs/docs-images/p11/04.png)

- このチャージ機能は、画面上部ナビゲーションバーの Credit 残高をクリックした際に表示される一覧の `Recharge` と同じものです。
![](../../../../../docs/docs-images/p11/05.png)
